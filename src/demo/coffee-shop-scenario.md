# Демонстрационный сценарий "Открытие кофейни"

## Описание сценария
Полнофункциональный демонстрационный сценарий для тестирования всех типов сообщений AI-агента в контексте открытия кофейни.

## Последовательность взаимодействия

### 1. Начало диалога
**Пользователь:** "Хочу открыть кофейню"

**Ожидаемый ответ агента:**
- Текстовое сообщение с приветствием
- Кнопки выбора режима (ММБ/КБ)
- Смена темы на зеленую после выбора режима

### 2. Выбор режима консультации
**Варианты:**
- **ММБ** (Модель малого бизнеса) - для проектов до 5 млн рублей
- **КБ** (Консалтинг бизнеса) - для масштабных проектов

**Ожидаемый ответ:**
- Коллапс с цепочкой рассуждений
- Переход к следующему этапу

### 3. Сбор данных о локации
**Ожидаемый ответ:**
- Форма для сбора информации:
  - Город/район
  - Тип локации (деловой центр, ТЦ, улица и т.д.)
  - Конкуренция в районе

### 4. Финансовый анализ
**Ожидаемый ответ:**
- Таблица с финансовыми расчетами:
  - Стартовые инвестиции
  - Ежемесячные расходы
  - Прогноз выручки
  - Чистая прибыль
  - Срок окупаемости

### 5. Визуализация планировки
**Ожидаемый ответ:**
- Изображение с примером планировки кофейни
- Оптимальная расстановка оборудования и посадочных мест

### 6. Полезные ресурсы
**Ожидаемый ответ:**
- Галерея ссылок на полезные материалы:
  - Бизнес-план
  - Руководство по оборудованию
  - Маркетинговые стратегии
  - Юридические аспекты

### 7. Прогресс анализа
**Ожидаемый ответ:**
- Прогресс-бар с текущим статусом анализа
- Процент выполнения и описание этапов

### 8. Быстрые ответы
**Ожидаемый ответ:**
- Кнопки быстрых ответов для продолжения:
  - Маркетинговая стратегия
  - Подбор персонала
  - Юридические вопросы
  - Техническое оснащение
  - Финансовые расчеты

## Типы сообщений в сценарии

### ✅ Поддерживаемые типы:
1. **Text** - текстовые сообщения с анализом
2. **Collapsible** - цепочка рассуждений агента
3. **Form** - формы для сбора данных
4. **Image** - визуализация планировки
5. **Links** - галерея полезных ссылок
6. **Table** - финансовые расчеты
7. **Progress** - прогресс-бары анализа
8. **Button Group** - интерактивные кнопки
9. **Quick Replies** - быстрые ответы

## Особенности реализации

### Задержки ответов:
- Симуляция печатания: 1500ms
- Задержка ответа: 200-500ms (случайная)
- Ошибки: 5% вероятность

### Контекст диалога:
- Сохранение данных пользователя
- Отслеживание прогресса сценария
- Автоматическая смена темы при выборе режима

### Интерактивность:
- Обработка кликов по кнопкам
- Сабмит форм внутри чата
- Быстрые ответы для продолжения диалога

## Тестирование функционала

### Команды для запуска:
```bash
npm run dev
```

### Тестовые фразы:
1. "Хочу открыть кофейню" - начало сценария
2. "ММБ" или "КБ" - выбор режима
3. "локация" - форма сбора данных
4. "бюджет" - финансовый анализ
5. "план" - визуализация планировки
6. "ресурсы" - полезные ссылки
7. "прогресс" - статус анализа
8. "дальше" - быстрые ответы

## Результат
После прохождения сценария пользователь получает полное представление о процессе открытия кофейни с демонстрацией всех возможностей чат-интерфейса AI-агента.
