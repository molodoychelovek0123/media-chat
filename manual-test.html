🧪 Тестирование сценария открытия кофейни

Инструкция по тестированию

Откройте приложение в новой вкладке и выполните следующие шаги:

Шаг 1: Инициализация сценария

Введите сообщение: "Хочу открыть кофейню"

Ожидаемый результат:

  • Агент отвечает готовностью помочь
  • Показываются кнопки выбора режима (ММБ/КБ)

Шаг 2: Выбор режима и смена темы

Нажмите кнопку: "ММБ - Модель малого бизнеса"

Ожидаемый результат:

  • Появляется сообщение от пользователя с текстом кнопки
  • Тема меняется на зеленую
  • Показывается reasoning-сообщение с открытым коллапсом

Шаг 3: Форма сбора информации

Введите: "локация"

Ожидаемый результат:

  • Автоматически показывается форма для сбора данных о локации
  • Форма содержит все необходимые поля

Шаг 4: Пошаговый сбор данных

Ответьте на вопросы агента:

  • Город: "Москва"
  • Тип локации: выберите из предложенных вариантов
  • Конкуренция: "Есть несколько кофеен поблизости"

Шаг 5: Анализ и быстрые ответы

Введите: "готово"

Ожидаемый результат:

  • Агент сообщает о заполнении формы
  • Показываются быстрые ответы для выбора типа анализа
  • При выборе "Финансовый анализ" показывается таблица

Шаг 6: Интерактивная карта

Введите: "карта"

Ожидаемый результат:

  • Агент показывает карту с возможными местами
  • Карта корректно отображается и интерактивна

Шаг 7: Открытие расчетного счета

Введите: "счет" → "нет"

Ожидаемый результат:

  • Агент спрашивает про счет → пользователь выбирает "нет"
  • Показывается форма с ИНН
  • Агент предлагает ознакомиться с условиями
